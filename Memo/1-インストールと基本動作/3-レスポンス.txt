from pydantic import BaseModel, Field #インポート
from datetime import datetime

# pydanticのBaseModelを継承(引数として使う)
class Contact(BaseModel): 
    id: int
    name: str
    email: str
    url: str
    gender: int
    message: str
    is_enabled: bool
    created_at: datetime

★コード解説★
テーブルのカラム名と型を指定している

★コード解説★

/contactのURLを開いたら、return内のデータが
表示される

response_model=list[contact_schema.Contact]
⇒schemas\contact.pyのContactクラスをimportしている
⇒schemasで記述したデータしか通信をおこなうことができない
⇒listメソッドを使うことで、複数のデータを処理できる
